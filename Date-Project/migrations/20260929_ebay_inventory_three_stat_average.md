# eBay 库存明细：近三次统计均销量与 Sheet 日期

本次复用 `ebay_inventory_pivot_snapshot`、`ebay_inventory_detail_history` 已保存的日期和明细 JSON。无需建表或修改字段。

## 统计口径

- 点击库存明细统一刷新时，本次新算出的「近30天销量」计作第 1 次，再读取该日期之前最近 2 个不同统计日期的冻结明细。当天旧快照不参与，重复刷新仍只有本次观测值。
- 每个历史日期先按站点＋核心码汇总该产品的「近30天销量」；无合法核心码时按站点＋完整 SKU 保持独立。不同品牌的同核心码归入同一产品，不跨站点。
- 「近3个月均销量」＝三次观测销量之和 ÷ 固定 3。历史日期不足两次或某日没有该产品时按 0 计；不能把少于三次的实际观测数当分母。均销量用于申购量和总库销比（月），计算用未舍入值，展示保留 2 位小数。
- 刷新只覆盖当天，既有历史日期保持原保存值，不因本次公式调整自动追溯重算。利润率仍按原先三个完整自然月订单金额计算。

## Excel

统一导出的三个 Sheet 均追加数据日期。单日示例：`Ebay库存明细-2026-09-29`；范围示例：`Ebay库存明细-20260801-20260831`。范围用紧凑日期避免超过 Excel 的 31 字符 Sheet 名长度限制，文件名保持原样。

部署需更新 Python 服务和 Vue 前端；Java 接口与数据库结构不变。部署后刷新当天快照才会看到新均销量。
