查询说明

输入 SKU 或 OE 号（支持多个），系统自动从 eBay 抓取搜索结果并按价格排序。

  • 选择"自动识别"时，先尝试作为 SKU 查找 OE，找不到则直接作为 OE 搜索。
  • 多个编号请用换行或逗号分隔，重复编号自动去重。
  • 类目锁定：两遍搜索，先探类目再锁价格，精确排除零件干扰。
  • Best Match：单遍搜索，eBay 默认排序保证相关性最高。
  • 勾选需要的商品后可导出为带图片的 Excel 文件。
