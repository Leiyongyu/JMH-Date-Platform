# 谷仓库龄每周刷新：周/月隔离

## 已确认的口径

- 库存明细“海外最高库龄”需要每周更新；原滞销清货和月度库存的月报口径必须保留。
- 谷仓接口：`POST /inventory/inventory_age_list`。请求体首轮`{"page":1,"page_size":200}`，随后页码递增；不传开始/结束日期、仓库或SKU。返回的是当次查询时账户可见的库龄批次数据，不是最近30天流水。
- 返回`code=0`才继续；读取`data.list`和`data.total`。完整拉取后才替换，返回0行或不足总条数则报错保留旧数据；最多10000页保护。
- 采集保留`warehouse_code`、`product_sku`、`warehouse_age`、`iba_quantity`及完整`raw_json`。页面按站点＋去首段前缀的SKU尾码匹配，并在同站点多仓/多批次中取最大库龄，0有效、缺失和冲突显示`--`。

## 原任务链与改造后的分工

| 任务 | 时间 | 写入及用途 |
|---|---|---|
| `pythonFbaInventoryTask.syncCurrentMonth()` | 每月1日22:30 | 谷仓月源→领星采购及头程月源→Python AMZ/eBay库龄成本→成都仓库龄；保持原样 |
| `operationSyncTask.syncGoodcangInventoryAge()` | 独立任务停用，仅保留手动入口 | 覆盖原当月月源；不要将它启用为周任务 |
| **`operationSyncTask.syncGoodcangInventoryAgeLatest()`** | **每周一06:00** | **仅写`jmh_data_platform.ods_goodcang_inventory_age_latest`，供Ebay库存明细使用** |

原月源仍为`jmh_data_platform.ods_goodcang_inventory_age_monthly`；Python月度成本仍为`date-project.dwd_ebay_inventory_age_cost_snapshot`。周任务不调用月报清洗链，不影响eBay补货2.0当前读月度DWD的库龄口径。

## 存储及失败规则

1. 周与月调用复用Java同一分页拉取、解析和校验代码，仅持久化目的表不同。每次周同步只保留最新的一批，没有周历史增长。
2. 所有页成功后，单事务删除latest旧行并分批插入新行（每批500）；不`TRUNCATE`，插入失败整体回滚。API失败/空数据/分页缺失不会先清表。
3. 周任务复用谷仓分组锁、运行日志和告警入口，禁止同一任务并发；锁被其他谷仓任务占用时沿用现有SKIPPED日志行为。
4. `snapshot_month`在latest里只是拉取归属月；页面读全表并验证只有一批，不根据月份挑旧行，不回退月表。
5. 初始化SQL只在latest为空且最新月源只有一批时复制初始数据；保留原拉取时间和批次号。重复执行不覆盖已更新的latest；源为空或混批时不复制，首次手动/定时成功刷新后才有值。

## 部署

1. 执行Java库脚本：`RuoYi-Vue-springboot3/sql/20260916_goodcang_inventory_age_weekly.sql`。脚本自带`USE jmh_data_platform`，建表与任务均在此库；没有DROP，也不删除任何原月度业务数据。
2. 部署新的Java包（包含`syncGoodcangInventoryAgeLatest`入口和最新表Mapper）、Python代码、ERP前端构建。
3. 重启Java让Quartz重新加载`sys_job`；只在数据库新增记录不代表运行中的Quartz已生效。Python未使用热重载时也需重启；浏览器刷新前端。
4. Java运行时区必须为`Asia/Shanghai`或等价的北京时间UTC+8。本地Windows为China Standard Time；Quartz沿用JVM默认时区。不要为此批量改其他任务的时区。
5. 新任务首次创建启用；重复SQL保留人工启停状态。cron为`0 0 6 ? * MON`，错过触发时刻不补跑（misfire_policy=3），可在任务管理手动执行一次新任务验证。**不要手动执行旧月快照任务来验证周任务。**

不会自动触发接口测试，也不自动重启服务。2026-09-16部署后，下一次计划触发为2026-09-21（周一）06:00，前提是新Java包已运行且任务启用。

## 验证SQL（只读）

```sql
USE `jmh_data_platform`;
SELECT job_id,job_name,invoke_target,cron_expression,status
FROM sys_job
WHERE invoke_target IN (
  'operationSyncTask.syncGoodcangInventoryAgeLatest()',
  'operationSyncTask.syncGoodcangInventoryAge()',
  'pythonFbaInventoryTask.syncCurrentMonth()');

SELECT COUNT(*) rows_count,COUNT(DISTINCT sync_batch_id) batch_count,
       MIN(pulled_at) min_time,MAX(pulled_at) max_time
FROM ods_goodcang_inventory_age_latest;

SELECT snapshot_month,COUNT(*) rows_count,MAX(pulled_at) pulled_at
FROM ods_goodcang_inventory_age_monthly
GROUP BY snapshot_month ORDER BY snapshot_month;
```

验收：latest仅1批且时间更新；旧monthly各月时间/行数不因周任务变化；Ebay库存明细页显示真实库龄拉取时间，库龄与latest同站点SKU最大值一致；月度库存/滞销库龄结果不变。
