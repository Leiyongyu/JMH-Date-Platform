## 范围与口径

- 只新增个人（OWNER）维度的“成都仓30天以上货值（仅eBay）”，位于90-180库龄成本之前；页面与Excel导出共用ctu_over_30_cost。
- 仅读取成都仓快照group_code=EBAY-1。Amazon其他仓库不参与个人归属，该列显示--；个人合计仅计eBay，不是组别页全部成都仓的合计。组别页、店铺页与滞销清货均保持原状。
- 快照月=源月stat_month的次月，即页面展示月；负责人规则用源月，与已有个人库存库龄规则相同，eBay产品SKU映射用快照月。
- 复用既有eBay品牌归属、JMH SKU还原及固定品牌规则。按每条明细的over_30_cost累加，不按SKU去重、不按比例摊，不重新计算成本；负数调整也保留。
- 匹配不到归“未分配”。只有成都仓成本、没有原报表行的负责人补充“仅库龄成本”行，原库存、销量、目标等保持空白，不虚构数值或重算原合计。
- 无eBay组别快照显示--；快照存在且个人无成本显示0。通过单次LEFT JOIN查询区分快照缺失与无成本，不新增逐SKU查询；负责人规则和产品映射复用本次请求已加载的数据。
