# eBay库存明细多选筛选（2026-09-21）

- SKU筛选改为数字中间码精确匹配：输入 `10053,20017,00123`，用英文逗号分隔。忽略两侧空格和重复项，保留前导零；`00123`与`123`不同，`10053`不会匹配`100530`。不再按完整SKU或后缀模糊搜索。
- 品牌、等级改为可搜索多选下拉，清空表示不限。各字段内为“或”，中间码、站点、品牌、等级之间为“且”。合并行仍按现有品牌/等级别名命中，匹配后保留整个合并行，不重新分摊数值。
- 每项筛选最多100个值、2048个字符。输入格式异常直接提示，不静默查询全部。
- 当前计算数据和指定日期历史明细使用相同过滤函数；先筛选再排序分页。历史缺中间码时只从冻结SKU提取用于匹配，不改快照、不去重原始历史行。
- 列表、全量导出、勾选导出共用筛选。改变条件后需点击查询，未应用的条件会阻止导出；改变多选项会清理旧勾选。
