# 脚本菜单——新增脚本指南

当前实现以`frontend/src/scripts.js`注册表和`scriptUrl.js`为准。**不支持openMode**；App.vue统一在新标签页打开，不能通过写embed/redirect改变行为。

## 注册

```js
{
  code: 'my-script',
  name: '我的脚本',
  description: '脚本用途',
  icon: 'MS',
  category: '效率工具',
  tags: ['Excel'],
  permission: 'sop:myScript:use',
  transport: 'proxy',
  page: '/index.html',
  proxyBase: '/sop/my-script/proxy',
  needSession: true,
}
```

- `transport=proxy`：经Java安全代理；page相对于代理基址；解析器添加api_base、erp_session。proxyBase可复用ERP下发的主机和/prod-api前缀。必须实现对应Java代理和Python路由，仅注册不能让路径自动出现。
- `transport=direct`：page为绝对URL或工作台当前origin下的路径，适合无后端、无敏感数据的个人静态工具；可设needSession=false。Python public文件构建后位于`/script-tools/<目录>/index.html`，不是自动挂载在站点根目录。
- `devBase`用于Vite本地开发的后备代理地址。当前解析器开发模式优先configured地址，独立代理需配置相应开发转发；生产验收从ERP入口进行。

## 权限必须两端一致

在jmh_data_platform.sys_menu中，按`sop:scriptTools:view`查父C菜单，新增F按钮，其perms必须等于注册表permission。给指定角色授权，不默认给所有人。按钮隐藏只控制可见性，Java代理必须逐次验证ERP会话和对应脚本权限，下载与写操作不能例外。

Python数据API使用现有require_internal_access；配置与Java一致的内部Token，只在后端转发，禁止传入浏览器、URL或日志。静态页面不等于数据接口已鉴权，FastAPI路由依赖也不会自动保护单独挂载的StaticFiles，需明确保护边界。

## 生效与验收

1. 构建Date-Project/frontend（npm run build），部署dist及Python代码；新增Python路由后重启服务。
2. 新增Java控制器或任务后编译并部署Java JAR；菜单数据按perms幂等插入，勿固定menu_id。
3. 分配角色权限，退出脚本中心再重新进入以取得新的会话及权限列表。
4. 无会话/伪造会话/无权限必须拒绝；带权限正常打开、调用、上传或下载；路径穿越拒绝。
5. 代理读取查询字符串会话时不要使用request.getParameter消耗表单请求体；二进制下载保留Content-Disposition，中文文件名使用UTF-8格式。
