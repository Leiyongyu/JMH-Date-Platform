# 首页 AMZ / eBay 店铺 SKU 价格分层部署包（2026-09-21）

## 范围与执行顺序

两张价格报表在首页第二排各占一半，可展开店铺查看站点，直接显示五档价格区间、SKU数及占比。AMZ保持人民币，eBay使用美元。本次不发布首页库存分析等其他本地开发内容。

1. 执行 **00_部署前检查_只读.sql**，确认数据库及10张表的存在情况。
2. 若6张依赖表缺失，只执行“依赖表_缺失时才执行”中对应文件。
3. 执行 **01_AMZ人民币报表建表.sql** 和 **02_eBay美元报表建表.sql**，共新增4张统计表，可重复执行。
4. 发布下述三端代码，分别点击两个卡片右上角“刷新”生成统计。
5. 执行 **99_部署后验证_只读.sql**，确认AMZ为CNY，eBay为USD。

## 重要：空表不会自动产生报表

源表必须已有完整原始批次、对应state和当月汇率。本包只建结构，不包含业务数据、密钥、源数据同步任务SQL，也不会调用外部接口。

本次提交只发布报表消费端，不额外发布eBay账号采集、Excel密钥管理、健康检查等其他开发中的功能。如果部署机尚未具备eBay官方刊登采集模块，或上述两张eBay源表没有数据，**eBay报表暂时无法生成**。需另行部署采集模块并成功拉取再刷新，不能用ebay_product_listing替代、不能伪造state。AMZ用已接入的领星独立原始刊登任务，不能用旧amz_product_listing替代。

源批次与行数校验不通过时拒绝覆盖报表。卡片刷新仅读本地数据，不拉外部接口、不同步汇率、不修改ODS；重算事务只覆盖本平台统计，失败保留旧报表。

## 发布三端代码

保留部署机.env.production、Python .env及账号文件，再正常拉取main，不要reset或覆盖本地配置。

- Java：在RuoYi-Vue-springboot3构建 `mvn -DskipTests package`，发布ruoyi-admin.jar并重启。本次新增两套报表路由，不能只更新前端。
- Python：更新Date-Project并重启现有服务，不额外启动第二个8010进程。
- Vue：在RuoYi-Vue3-master执行 `npm run build:prod`，将dist发布到实际Nginx静态目录。
- 登录首页，第二排应出现“AMAZON · 人民币价格结构”和“EBAY · 美元价格结构”。首次均需点击卡片刷新。

Java路由：GET /operations/{amz,ebay}/price-tier/summary；POST /operations/{amz,ebay}/price-tier/refresh。
Python路由：/api/v1/finance/{amz,ebay}-price-tier/summary及/refresh。

复用权限 operations:amzReplenishment:list、operations:ebayReplenishmentV2:list，无新增菜单权限或定时任务SQL。看不到卡片时检查/getInfo中的权限；Python仍校验内部Token。

## 口径

- AMZ：status=1且is_delete=0，seller_sku及landed_price；当月my_rate换人民币，CNY原价直接使用。
- eBay：官方账号在售刊登SKU/当前价；多规格按变体SKU及价格，不重复计父商品。USD直接用原价，其他外币×本币当月rate_org÷USD当月rate_org，CNY直接÷USD当月rate_org。
- 月份为计算时北京时间年月，异常或缺汇率不回退旧月/其他汇率字段，该记录不归档并提示；USD原价无需汇率。
- AMZ：0≤p<340、340≤p<680、680≤p<1020、1020≤p≤1690、p>1690。
- eBay：0≤p<50、50≤p<100、100≤p<150、150≤p≤250、p>250。
- 店铺+站点+完整SKU去重，多价格取最低有效换算价。跨站点分别计数，店铺等于站点相加。
- AMZ去掉店名末尾与country_code一致的国家后缀合并店铺。不改为负责人统计规则、不按中间码合并、不排除PC前缀。
- 各档占比以本节点成功划档SKU数为分母，异常单列提示；店铺按SKU总数降序。
- eBay美元读独立新表，不把旧人民币档位直接改美元标签。旧人民币/六档统计保留但不再读取。

## 验收

99脚本应返回amz/CNY和ebay/USD。展开站点，各档加总应等于店铺档位。只加总SITE，不要与SHOP重复累计。
源数据或汇率月份改变时提示重算，不自动拉接口。

本地2026-09-21参考：eBay美元37店铺、73站点组、17,029有效SKU，五档8,816/3,252/1,579/1,962/1,420。不同环境/批次无需一致。
AMZ既有550条landed_price缺失会提示未归档，不应当作0强行归低价档。
