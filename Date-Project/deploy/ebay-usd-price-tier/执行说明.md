# eBay首页美元价格结构（2026-09-21）

本说明替代旧人民币价格方案中的eBay部分；AMZ仍按当月my_rate换算人民币，340/680/1020/1690分档，不变。

## 换算与分档

- 原币USD：直接用原价，不要求USD汇率存在。
- 其他外币：美元价 = 原价 × 当月该币种rate_org ÷ 当月USD的rate_org。第一步先换人民币，第二步换美元。
- 原币CNY：已是人民币，直接除以当月USD的rate_org。
- 汇率表为Python库的dim_lingxing_currency_month；月份为实际计算时的北京时间年月。缺失、非正、异常汇率对应记录不计入档位并提示，不回退旧月份、不回退my_rate。USD原价不受其他币种汇率缺失影响。
- 五档：0≤p<50；50≤p<100；100≤p<150；150≤p≤250；p>250。250属于高客单层。0为有效原价。
- 使用精确有理数执行两步换算并比较边界，不先舍入汇率或价格。
- 不改变原有店铺＋站点＋完整SKU去重，同组取最低有效换算价格，多规格按变体、不计父商品；跨站点数量相加。店铺仍按有效SKU总数降序，不改变店铺排序键。

3. 点击eBay价格结构右上角刷新按钮：只读取本地已拉取数据，重新计算并事务覆盖新美元统计表。失败保留旧的美元统计；旧人民币统计留在原表，不转换旧档位计数。
4. 新前端拒绝把旧Python返回的人民币报表当美元显示，会提示更新服务。

GET只读已发布美元报表。原始批次、计算月份或rate_org变更后提示重新统计。报表不自动拉取接口，不自动同步汇率。
