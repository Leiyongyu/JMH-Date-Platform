# 同步告警邮件配置

同步、Quartz、后台任务和 eBay 凭证提醒统一通过 SMTP 发送，不再调用企微群机器人。发送失败不会回退到群消息。默认仅开启失败告警，保留原有去重规则。

## 私密配置

在运行 Java 服务的账户主目录下创建 `.jmh-platform/alert-mail.properties`。部署机必须另行配置，本机文件不会随 Git 推送。

```properties
sync.alert.mail.host=smtp.exmail.qq.com
sync.alert.mail.port=465
sync.alert.mail.ssl=true
sync.alert.mail.username=leiyongyu@jumachscm.com
sync.alert.mail.password=填写邮箱SMTP授权码
sync.alert.mail.to=leiyongyu@jumachscm.com
```

也可以设置服务进程环境变量 `SYNC_ALERT_MAIL_CONFIG` 为该文件的绝对路径（Windows 建议使用正斜杠）。只允许运行服务的账户和管理员读取私密文件，不要提交授权码到仓库。

更新代码后重新打包并重启 Java 服务。SMTP 配置不涉及 SQL 表结构。缺少配置时仅记录未发送日志，不发送企微群消息；启用前应确认测试邮件已收到。

## 补货建议分页保护

每批店铺独立读取。分页总数缺失或发生变化时，从第一页重新读取该批，最多读取三轮。错误日志包含店铺 SID、分页偏移量和前后总数。所有批次校验通过后，才在事务中替换补货建议源数据；失败保留原数据。此重试不保证上游持续变化时同步一定成功。
