Design Spec · Icons v1

图标与图标按钮规范

刷新、导出、筛选、列设置这些动作用「纯图标按钮 + 悬停气泡」，不再用边框包文字。图标采用 Lucide 线性图标库（ISC 协议，按需打包），菜单与业务图标继续用你现有的 SVG 雪碧图，两套互不冲突。

01

图标从哪来

组件只认一个 name，内部按三级顺序自动匹配。你写页面时不用关心来源。

① 语义名 → Lucide
refresh export filter columns 这类小驼峰名字，走 Lucide 线性图标。
新增依赖只有一个：lucide-vue-next@0.577.0，按需 tree-shake，实际打进包里的只有用到的那些。
② PascalCase → Element Plus
Refresh Promotion 这类大写开头，走已安装的 293 个 EP 图标，个别 EP 独有的图标（如 Promotion、SoldOut）还能继续用。
③ 其他 → 你的 SVG 雪碧图
shopping money chart jmh 这些你 src/assets/icons/svg 里已有的文件名，继续走 <svg-icon>，91 个全部保留可用。
④ jmh- 前缀 → 业务图标
你已有的 src/assets/icons/svg/jmh/ 子目录，引用名是 jmh-refresh、jmh-export、jmh-trend-up 这种。AppIcon 直接把名字透传给 <svg-icon>，所以这 5 个今天就能在 icon-btn 里用。
新增业务图标仍放这个目录，记得同步 README 清单——tests/jmh-icon-library.test.mjs 会校验两者一一对应。
ℹ️
为什么工具条用 Lucide 而不是 EP？你现有 91 个菜单图标是实心 1024 风格，EP 也是实心，两者在 14px 工具条里都偏粗；Lucide 是统一 1.9px 线性，小尺寸更清晰。
但要注意上面第 ④ 行最后一个图标：jmh-refresh 是实心 1024，和线性图标并排会明显偏重。所以分工是——通用动作 → Lucide，jmh-* 只用于独立的业务标记（涨跌箭头、平台标识这类单独立着的图标），不混进同一条工具条。
02

图标按钮规格

四尺寸、四类型、六状态。默认无边框无底色，只在悬停时出现浅底。

尺寸
xs 24 / 12 sm 28 / 14（表格工具条默认） md 32 / 16（页面动作） lg 36 / 18
类型
default 透明 primary 实心 ghost 描边 danger 危险
状态
默认 悬停 选中 禁用 加载中 键盘焦点
图标 + 文字
图标已能表达的一律纯图标；有歧义的才配文字
角标
消息、待办用数字角标，不用红点

左边四个圆形描边按钮并排，像一组开关，和筛选区的「查询/重置」抢同一层注意力；右边去掉边框，只留图标。

⚠️
热区说明：28px 图标按钮只适合桌面端鼠标操作。移动端或触屏场景会把同样的按钮放大到 36px（size="lg"），保证 ≥ 32px 的可点面积，不会为了好看牺牲可用性。

06

怎么用

两个组件已在 main.js 全局注册，页面里不用 import。

<!-- 工具条：纯图标，悬停出气泡 --> <icon-btn icon="refresh" tooltip="刷新" size="sm" @click="handleRefresh" /> <!-- 带加载态 --> <icon-btn icon="refresh" tooltip="重新计算" :loading="recalculating" /> <!-- 主操作：实心 + 文字 --> <icon-btn icon="export" label="导出全部数据" type="primary" /> <!-- 开关类：active 表示开启 --> <icon-btn :icon="showSearch ? 'eye' : 'eyeOff'" :active="showSearch" tooltip="显示搜索" /> <!-- 单纯要一个图标 --> <app-icon name="shopping" :size="18" /> <!-- 自定义图标（不在这张表里）--> // 1. 把 xxx.svg 丢进 src/assets/icons/svg/ // 2. 直接 <icon-btn icon="xxx" />，自动兜底到雪碧图
