Design Proposal · v1

JMH 跨境 ERP 视觉重构方案

保留现有业务逻辑与全部接口调用，仅重构视觉系统、信息层级与页面骨架。目标是去掉模板化的「后台感」与通用 AI 风格，建立一套高密度但安静的跨境电商数据工作台。

项目RuoYi-Vue3 / JMH ERP
页面规模85 个视图 · 52 个含独立样式
技术栈Vue 3 · Element Plus · ECharts
01

现状诊断

当前界面是 RuoYi 标准模板的直接产物。它在功能上完整，但视觉上没有传达「跨境电商数据平台」的专业度，反而更像一套通用权限管理系统。

无品牌

主色是框架默认蓝

全局主色 #409EFF 是 Element Plus 出厂值，与 logo 的深蓝→青渐变毫无关联。任何 RuoYi 项目打开都是同一个颜色。

视觉噪音

表格过载

全量 1px 边框 + 斑马纹 + 居中混排，在 20+ 列的库存 / 利润报表里横向竖向都在抢注意力，数据本身反而看不清。

层级缺失

区块全靠边框区分

筛选、工具条、表格、分页都是白底加边框，缺少留白节奏与卡片层级，用户很难一眼定位「我在哪一步」。

布局僵硬

内联样式割裂

大量 style="width:160px" 散落在模板里，筛选区排布靠人肉对齐，窄屏下换行错位，无法统一响应式收敛。

02

视觉主题

主题直接从你的 logo 提取基因：左侧深蓝代表跨境的「远」与信任，右侧青色代表数据与流动。两者组成一套冷色双主色系统，彻底摆脱紫色渐变这类典型 AI 审美。

Theme · 01

深海蓝 · 潮汐青

用深墨蓝承担结构（导航、标题、主操作），用青色承担数据反馈（正向增长、健康状态、图表辅助色）。页面底色改为极浅冷灰，让白色卡片浮起来，形成「纸与桌面」的关系，而不是一整块灰蓝。

03

字体与数字规范

ERP 的核心是读数字。所有数值一律使用等宽数字（tabular-nums），保证列对齐后末位不抖动；正文字号整体下调 1px 换取信息密度，靠字重和颜色而不是字号建立层级。

04

组件语言

06

落地规范

全部改动集中在 src/assets/styles 与视图层的模板结构，不触碰 src/api 下任何请求、参数与返回处理。

布局骨架

  • 侧边栏 200 → 236px，浅色优先，收起 56px
  • 顶部条 50 → 56px，标签页 36px 一体化
  • 内容区内边距统一 16–20px
  • 页面结构固定四段：页头 / 指标 / 筛选 / 数据

表格与数据

  • 移除 border 与 stripe，仅保留横线
  • 表头 11.5px / 600 / #F7F9FC 底
  • 数值列右对齐 + tabular-nums
  • 行高 40px，hover #F7FAFF，首列固定
  • 状态统一胶囊，不再用纯文字标签色块

深色模式

  • 底色 #0B1220，卡片 #111C2E，不再用纯黑
  • 主色自动提亮到 #4D8DF5，保证 4.5:1 对比
  • 边框降为 rgba(255,255,255,.08)
  • 图表网格线与文字同步降噪

可访问性

  • 正文对比度 ≥ 4.5:1，大字 ≥ 3:1
  • 焦点环统一 2px #1257D6 + 2px 偏移
  • 点击热区最小 32×32（移动 44）
  • 颜色不作为唯一信息载体，状态胶囊带文字

图表色板

  • 主序列 #1257D6，辅序列 #12B2A6
  • 扩展 6 色：#5B8DEF #0E9E96 #D97706 #7C6CF0 #12A150 #8A99B0
  • 网格线 #EEF2F8，去 3D 与阴影
  • 涨红跌绿，与利润表口径一致

改造顺序

  • 第 1 步：设计变量 + Element 主题覆盖（全局生效）
  • 第 2 步：Layout 三件套（侧边栏 / 顶栏 / 标签页）
  • 第 3 步：登录页与首页看板
  • 第 4 步：高频业务页（库存 / 利润 / 补货）
  • 第 5 步：其余页面样式收敛
