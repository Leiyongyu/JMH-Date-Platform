整套图形语言长什么样

单个图标好看不算数，要看 40 个摆在一起是否还统一。下面是 Solar Bold Duotone 里与你业务直接相关的 42 个图标，同一套笔触、同一套圆角半径、同一套内描边留白——这是判断一套图标能不能撑起整个系统的关键。

07

怎么接进你的项目

三条路都能落地，差别在依赖重量和维护成本。你已经有 src/assets/icons/svg 雪碧图机制，第三条几乎零成本。

A · 官方包 推荐
npm i @solar-icons/vue

// 按风格取子路径，tree-shaking
import { RefreshIcon } from
  '@solar-icons/vue/bold-duotone'

<RefreshIcon size="20"
  color="#1257D6"
  secondaryColor="#12B2A6"
  :secondaryOpacity="0.2" />
官方维护、类型完整、duotone 第二层可单独换色
B · Iconify 多集混用
npm i @iconify/vue @iconify-json/solar

import { Icon } from '@iconify/vue'

<Icon icon="solar:refresh-bold-duotone"
      :width="20" />
一个组件通吃 200+ 图标集，适合以后混用多套
C · 本地 SVG 零依赖
# 放进现有雪碧图目录
src/assets/icons/svg/
  refresh.svg

<!-- 页面直接调用 -->
<svg-icon icon-class="refresh" />
不增依赖、离线可用，但换图标要手动下文件
推荐
Solar · Bold Duotone（操作）+ Linear（导航）
1,517 个图标 × 6 种风格 = 9,102 个变体，从 14px 工具条到 48px 看板图标都有对应形态。粗线圆角在中文小字环境里辨识度最高，双色调让图标自带体积感，而不是一圈细线。

双档制：操作按钮用 duotone 20px（有存在感），侧边菜单用 linear 18px（不抢文字），层级自然分开。
更保守的选择
Phosphor · Duotone（MIT 授权）
9,072 个变体、6 种字重，同样是双色调路线，但笔触更方、更中性，图形语言偏工程规范而非消费级。

硬优势只有一条，但很关键：MIT 授权，商业使用零约束。如果团队对开源授权审查严格，这个最省事。
先把授权讲清楚：Solar 采用 CC BY 4.0——可商用、可修改、可闭源分发，但需在产品文档或「关于」页保留一行署名。Phosphor 与 Iconoir 是 MIT，无署名要求。两者都不要求开源你的代码。如果完全不想要署名义务，选 Phosphor。
